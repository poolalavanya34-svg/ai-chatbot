# Local AI Chatbot

A feature-rich, full-stack web application built using **Flask** and powered locally by **Ollama**. This application provides an interactive chatbot interface without relying on paid external APIs or database dependencies.

## 🌟 Key Features
- **Local AI Model Integration:** Runs fully offline using Ollama models.
- **Clean UI Interface:** Responsive web layout for seamless conversation flow.
- **Voice & Media Support:** Voice-to-text input and media file handling.
- **Chat History Management:** Export and manage ongoing sessions easily.

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **AI Infrastructure:** Ollama (Local LLM)

## 🚀 How to Run Locally

### Prerequisites
1. Install [Python](https://www.python.org/) (v3.8+).
2. Download and install [Ollama](https://ollama.com/).
